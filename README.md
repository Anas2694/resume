# Mohd Viquaruddin Anas Resume Portfolio

## Overview

This project provides recruiters and hiring managers with a streamlined web interface to view and interact with professional credentials. It wraps a standard document in a responsive web viewer, ensuring the information is easy to read across all devices without requiring immediate manual downloads.

## Installation

Follow these steps to set up the project locally on your machine.

Clone the repository:

```bash
git clone https://github.com/Anas2694/resume.git
```

Navigate into the project directory:

```bash
cd resume
```

Since the project consists of static files, you can use any basic HTTP server to serve it locally. If you have Python installed, you can start a local server like this:

```bash
python -m http.server 8000
```

## Usage

Once the local server is running, open your browser and navigate to `http://localhost:8000`. You will see a customized interface displaying the resume.

The interface includes a built-in document viewer that scales to fit both mobile screens and large desktop monitors. The top navigation bar provides two direct actions for users:
* **Open PDF**: Opens the raw document in a new browser tab for native browser viewing or printing.
* **Download**: Triggers a direct download of the document file to the user's device.

If you are deploying this project to Vercel, the included configuration automatically handles routing. Visitors who navigate to the `/resume` path will be permanently redirected to the raw PDF file, keeping URLs clean and professional.

## Features

* **Embedded Document Viewer**: Displays the resume directly in the browser without requiring external software.
* **Responsive Design**: Adapts seamlessly to mobile phones, tablets, and desktop displays.
* **Direct Actions**: Includes prominent buttons for viewing the raw file and downloading the document.
* **Automated Routing**: Utilizes Vercel configuration for clean URL redirects.
* **Modern Interface**: Features a clean aesthetic with glassmorphism effects and modern typography.
